# 林嘉玉 · 个人作品集

React + Vite 基础版本，深色主题，最大版心 1700px，兼容桌面与窄屏。

## 运行

使用 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端输出的本地地址。生产构建：`npm run build`；预览构建：`npm run preview`。

## 内容与维护

- `src/main.jsx`：个人简介、教育经历、项目数据、能力及联系方式。
- `src/style.css`：整体配色、布局、断点与项目概念封面。
- `public/assets/portrait.jpg`：从用户提供的简历中提取的本人头像。
- 首页整合用户提供的 React Bits CircularCarousel 组件：3D 圆柱环绕、旋转入场、自动轮播、拖动、悬停暂停、键盘方向切换与 Enter 打开详情。使用 8 张本地 SVG 概念封面，无外部图片依赖。组件位于 `src/CircularCarousel.jsx` 和同名 CSS。
- 三个项目均依据简历整理。封面是代码绘制的概念视觉，已明确标注，不代表真实交付作品。后续可替换成项目图片。
- AI 设计内容为探索方向，未虚构 AI 项目或客户案例。
- 电话在简历中已脱敏。完整电话、邮箱、微信待用户提供，未虚构联系方式。底部提供复制作品集链接功能；本地链接仅当前电脑可用。
- 当前未上线、未连接表单或分析服务。

## GitHub Pages 部署

项目已加入 `.github/workflows/deploy-pages.yml`。推送到 GitHub 的 `main` 分支后，在仓库 Settings → Pages 中把 Source 设为 GitHub Actions；以后每次推送都会自动重新构建并发布。Vite 使用相对资源路径，可同时兼容用户名主页和普通项目仓库地址。
